# Astro-Engine
<p>
Astro-Engine is a game dev framework made by Manas Manushya that is made in order to make game making easier than before. This game framework is available for java, which makes it better as java is one of the simplest languages while keeping its reaches balanced.
</p>

This library currently includes:
1. **An ECS System** to manage entities
2. **AWT's graphics support** to render GUI objects way easier than OpenGL's rendering system.
3. **texture packing** that can be edited very easily and is work efficient 
4. **Animation** system that lets us animate objects easily, can also animate a texture pack.
5. **Camera** that helps us move the view all around the world.
6. **Shader** support to draw graphics using glsl code.

I started making this project as a game dev framework to make the game that I was trying to make since a lot of time. I am going to be continuously working on this project for maybe like a year cz I don't have much else to do except for assignment and preparation for exams.
